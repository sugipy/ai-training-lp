「やりました」まで。

Slackで受けた依頼を、メンション1つでタスクに。期限の前後に自動でリマインドして、完了まで見届けます。流れて消えていく依頼を、探す手間を減らします。

Slackの依頼は、なぜ埋もれるのか

依頼は流れる。頼んだ側は忘れ、頼まれた側は見落とす。

🌊

スレッドに流れて見失う

「やっておきます」のひと言は、翌日にはタイムラインの下。誰も悪くないのに、抜け落ちます。

📝

別ツールへの転記が続かない

タスク管理ツールに写す手間があるうちは、運用が定着しません。

😶

催促するのが気まずい

人から言われると角が立つ催促も、アプリなら自然に届きます。

使い方は、3ステップだけ

覚えることはメンションひとつです。

絵文字リアクションでもメッセージのショートカットでもタスクにできます

1

メンションでタスク化

@リマインドくん をつけるだけ。絵文字リアクションや、メッセージのショートカット「タスクにする」でも作れます。

2

AIが中身を整理

タスク名の要約、担当、依頼者、「金曜18時」のような期限まで、文面から自動で読み取ります。

3

期限に合わせて自動で催促

担当者へのDMと元スレッドでリマインド。ボタン1つで完了にできます。

毎日2回、DMで
「今日やること」が届く

平日 9:00 と 16:00 に、期限が前日・当日・超過のタスクをまとめてお知らせします。

  • 各行のボタンから、そのまま完了・期限変更
  • 期限を過ぎたら、翌営業日から元スレッドで催促
  • 5回催促しても動かないタスクは、自動で「保留」へ
  • 土日・祝日は催促を止めて、休み明けから再開

そのほかの機能

必要になってから使えば十分なものを、ひと通り用意しています。

🖥️

タスクポータル

「今日やること」「タスク一覧」「振り返り」をブラウザで確認。Slackでログインするだけです。

🔒

見える範囲は Slack と同じ

自分が関わるタスクと、参加しているチャンネルのタスクだけが見えます。見える範囲はSlackの参加状況に合わせています。

🗂️

Notion と同期

タスクの状態と期限を、Notionのデータベースと双方向で同期できます（利用時にNotionの接続設定が必要です）。

📊

週次の振り返り

今週の作成数・完了数を集計。チームの動きを数字で振り返れます。

🤖

Claude Code から操作

MCPに対応。手元のClaude Codeから、自分のタスクの確認・追加・完了ができます。

🇯🇵

日本の働き方に合わせた設計

日本の祝日・休日に対応し、期限の読み取りも日本語の言い回しを前提にしています。
